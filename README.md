# 🤖 Discord Бот (Аудит Логи + Тикеты + Войсы + Уровни + Розыгрыши)

Мощный и готовый к работе бот для Discord на Python (`discord.py` 2.x) со встроенным подробным логированием всех действий на сервере, тикет-системой, динамическими войс-каналами, системой уровней активности и интерактивными розыгрышами с отправкой призов в ЛС.

---

## 📋 Возможности бота

### 1. 📜 Полное логирование действий на сервере (Аудит)
Бот отправляет красивые Embed-уведомления в настроенный канал логов:
- **Сообщения**:
  - Удаление сообщений (автор, канал, текст, прикрепленные файлы).
  - Редактирование сообщений (текст «до» и «после», ссылка на сообщение).
- **Участники**:
  - Вход нового участника (с датой создания аккаунта и общим счётчиком участников).
  - Выход участника (с информацией о ролях и времени на сервере).
  - Изменение никнейма на сервере.
  - Изменение ролей участника (какие роли выданы / сняты).
  - Выдача и снятие таймаута (мута) модерацией.
- **Голосовые каналы**:
  - Подключение к каналу, отключение, перемещение между каналами.
- **Модерация**:
  - Блокировка (бан) с указанием модератора и причины из журнала аудита.
  - Разблокировка (разбан).
- **Каналы и роли**:
  - Создание, удаление и изменение каналов (тема, медленный режим, имя).
  - Создание, удаление и изменение ролей (название, цвет, права).

---

### 2. 🎫 Полноценная тикет-система
- **Интерактивная панель**: сообщение с кнопкой `📩 Создать тикет` в выбранном канале.
- **Модальное окно**: при нажатии пользователю открывается форма для ввода темы и описания проблемы.
- **Приватность**: создается закрытый текстовый канал, доступный только автору тикета и роли поддержки/администраторам.
- **Управление внутри тикета**:
  - 🔒 **Закрыть**: закрывает тикет с подтверждением, генерирует файл транскрипта (`.txt`), отправляет его в ЛС автору и в канал логов тикетов, после чего безопасно удаляет канал.
  - 📑 **Транскрипт**: выгрузка текущей переписки прямо во время диалога.
  - 🙋‍♂️ **Принять тикет**: модератор может закрепить обращение за собой.
- **Постоянство (Persistent Views)**: кнопки продолжают работать даже после перезагрузки бота!

---

### 3. 🔊 Динамические голосовые каналы (Join to Create)
- **Авто-создание**: при входе в хаб-канал (например, `➕ Создать канал`) бот моментально создаёт для пользователя личный голосовой канал и перемещает его туда.
- **Интерактивная панель в чате войса**: в текстовый чат голосового канала отправляется панель с кнопками:
  - ✏️ **Название** — сменить название своего голосового канала через всплывающее окно.
  - 👥 **Лимит** — установить ограничение количества участников (0–99).
  - 🔒 **Закрыть / Открыть** — переключение доступа в канал для остальных участников.
  - 👁️ **Скрыть / Показать** — скрыть канал из списка серверов для других.
  - 🚫 **Выгнать** — меню исключения и блокировки нежелательного участника в канале.
  - 👑 **Передать права** — передать право владения комнатой другому участнику.
  - 🗑️ **Удалить** — закрыть и удалить комнату вручную.
- **Авто-очистка**: как только все участники покидают комнату, бот автоматически удаляет пустой канал.
- **Передача владельца**: если создатель выходит, пока в канале есть другие люди, статус владельца передаётся следующему участнику.

---

### 4. 🎁 Система интерактивных розыгрышей (Giveaways)
- **Интерактивные кнопки**: сообщение с кнопками `🎉 Участвовать (N)` и `👥 Участники` (быстрый вход и выход по клику).
- **Разграничение прав доступа**: создавать и управлять розыгрышами могут только администраторы сервера, участники со специальной ролью ведущего (`/set-giveaway-role`) или пользователи с персональным доступом (`/add-giveaway-manager`). Обычные участники без разрешения использовать команды не могут!
- **Личные сообщения победителям (DM)**: бот автоматически отправляет победителю в ЛС секретный текст, промокод или инструкцию по получению приза.
- **Автоматический таймер**: умный парсер времени (`30s`, `15m`, `2h`, `1d`, `1д`, `2ч`), автоматическое определение случайных победителей при окончании времени.
- **Условия для участия**:
  - Обязательная роль (`required_role`).
  - Минимальный уровень активности на сервере (`min_level`) — синергия с системой уровней!
- **Управление розыгрышами**:
  - Настройка роли ведущего розыгрышей (`/set-giveaway-role`).
  - Персональный доступ участникам (`/add-giveaway-manager`, `/remove-giveaway-manager`).
  - Просмотр настроек доступа (`/giveaway-access`).
  - Настройка текста в ЛС (`dm_text` в `/gstart` или через `/gsetdm`).
  - Досрочное завершение с выбором победителей (`/gend`).
  - Перевыбор случайных победителей (`/greroll`).
  - Просмотр списка активных розыгрышей на сервере (`/glist`).
  - Отмена розыгрыша (`/gcancel`).
- **Надёжность**: состояние сохраняется в `data/giveaways.json`, кнопки продолжают работать даже после перезагрузки бота.

---

### 5. ⭐ Система уровней и активности (Leveling)
- **Опыт за сообщения**: от 15 до 25 XP за сообщения в чате (с защитой от спама, кулдаун 60 секунд).
- **Опыт за общение в войсе**: 10-15 XP каждую минуту при общении в голосовых каналах (от 2 человек).
- **Карточка ранга `/rank`**: прогресс-бар, место в топе сервера, уровень, сообщения и часы в войсе.
- **Таблица лидеров `/leaderboard`**: Топ-10 активных участников с медалями 🥇, 🥈, 🥉.
- **Автоматическая смена ролей-рангов (замена старых ролей)**: при переходе в следующий диапазон (например, с 10-20 на 20-30) бот автоматически выдает новую роль и **снимает предыдущую**, чтобы у участника всегда был только его актуальный ранг!
- **Переключение режимов**: возможность переключить систему между заменой ролей (ранги) и накоплением всех полученных ролей (`/set-level-roles-mode`).

## 🚀 Пошаговая инструкция по настройке и запуску

### Шаг 1. Создание бота на портале Discord
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **«New Application»** в правом верхнем углу, введите имя (например, `ServerAssistant`) и подтвердите.
3. В меню слева перейдите во вкладку **«Bot»**:
   - Нажмите **«Reset Token»**, скопируйте полученный токен (сохраните его, он понадобится в `.env`).
4. **ВАЖНО! Включение Intents (Намерения шлюза):**
   - На этой же странице во вкладке **«Bot»** прокрутите вниз до раздела **«Privileged Gateway Intents»**.
   - Включите все три галочки:
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent** *(нужен для логов входа/выхода/ролей участников)*
     - ✅ **Message Content Intent** *(нужен для чтения сообщений и системы уровней)*
   - Нажмите **«Save Changes»** внизу.

---

### Шаг 2. Приглашение бота на ваш сервер
1. В левом меню выберите **«OAuth2»** ➔ **«URL Generator»**.
2. В блоке **Scopes** отметьте:
   - ✅ `bot`
   - ✅ `applications.commands` (для слэш-команд `/`)
3. В появившемся блоке **Bot Permissions** выберите:
   - ✅ `Administrator` (рекомендуется для корректной работы всех функций тикетов и аудита)
4. Скопируйте ссылку в самом низу (**Generated URL**), откройте в браузере и добавьте бота на ваш сервер.

---

### Шаг 3. Настройка токена
1. В папке с ботом найдите файл `.env`.
2. Откройте его в блокноте или любом редакторе и вставьте ваш токен:
   ```env
   DISCORD_TOKEN=ваш_скопированный_токен_здесь
   COMMAND_PREFIX=!
   # Опционально (если требуется прокси): DISCORD_PROXY=http://127.0.0.1:10808
   ```
3. Сохраните файл.

---

### Шаг 4. Запуск бота
- **Способ 1 (самый простой для Windows):**
  Дважды кликните по ярлыку **«Запустить Discord Бота.bat»** на Рабочем столе (или по файлу `run.bat` в папке бота).
  Он сам проверит зависимости и запустит бота.

- **Способ 2 (через терминал/командную строку):**
  ```bash
  python -m pip install -r requirements.txt
  python bot.py
  ```

## 🛠️ Настройка на сервере Discord (Слэш-команды)

После запуска бота введите на вашем сервере следующие слэш-команды:

### 🎁 Розыгрыши (Giveaways)
1. **/gstart** `prize:Приз` `duration:Время` `[winners:1]` `[channel:#канал]` `[description:Правила]` `[required_role:@Роль]` `[min_level:Уровень]` `[dm_text:Текст_в_ЛС]`
   > Запускает интерактивный розыгрыш. Доступно только администраторам или участникам с настроенным разрешением (роль/пользователь).
2. **/gsetdm** `message_id:ID` `dm_text:Текст_в_ЛС`
   > Настраивает или изменяет секретный текст, отправляемый победителю в ЛС (виден только победителю).
3. **/gend** `message_id:ID`
   > Досрочно завершает розыгрыш и определяет победителей с отправкой призов в ЛС.
4. **/greroll** `message_id:ID` `[winners:1]`
   > Выбирает новых случайных победителей среди участников завершенного розыгрыша с отправкой ЛС.
5. **/gcancel** `message_id:ID`
   > Отменяет розыгрыш без выбора победителей.
6. **/glist**
   > Показывает список всех активных розыгрышей на сервере со ссылками и таймерами.
7. **/set-giveaway-role** `[role:@Роль]`
   > Назначает роль ведущего розыгрышей. Участники с этой ролью получают право создавать и управлять розыгрышами (без выдачи полных прав администратора). Вызов без указания роли сбрасывает настройку.
8. **/add-giveaway-manager** `user:@Пользователь`
   > Предоставляет конкретному участнику персональное право на создание и управление розыгрышами.
9. **/remove-giveaway-manager** `user:@Пользователь`
   > Отзывает персональное право на управление розыгрышами у участника.
10. **/giveaway-access**
    > Показывает текущие настройки прав: кто может создавать розыгрыши (роль, список персональных пользователей, администраторы).

### ⭐ Система уровней и активности (Leveling)
7. **/rank** `[user:@пользователь]`
   > Показывает карточку активности: уровень, опыт (XP), полосу прогресса, место в топе сервера, количество сообщений и время в войсе.
8. **/leaderboard**
   > Выводит таблицу лидеров сервера (Топ-10) по опыту и уровням с медалями 🥇, 🥈, 🥉.
9. **/set-level-channel** `[channel:#канал]`
   > Назначает канал для поздравлений с новыми уровнями (или отправка в текущий).
10. **/set-level-role** `level:5` `role:@Активный`
    > Настраивает автоматическую выдачу роли при достижении уровня.
11. **/level-roles**
    > Список всех настроенных ролей за уровни с указанием диапазонов действия (например, 10–19, 20–29) и текущего режима.
12. **/set-level-roles-mode** `mode:Заменять старые роли (ранги) / Накапливать`
    > Переключает режим работы ролей: заменять старую роль при переходе на следующий диапазон (по умолчанию) или накапливать все полученные роли.
13. **/remove-level-role** `level:5`
    > Удаляет роль-награду за уровень.
14. **/add-xp** / **/remove-xp** / **/reset-levels**
    > Управление опытом участников (выдача, списание, сброс).

### 🎭 Автовыдача ролей (Autorole)
14. **/set-autorole** `role:@Роль` *(опционально)*
    > Настраивает роль, выдаваемую каждому новому участнику при входе. Для отключения вызовите без роли.

### 🔊 Динамические голосовые каналы
15. **/setup-voice** `category:Категория` `hub_name:➕ Создать канал`
    > Создаёт хаб «Join to Create» с панелью управления комнатой в чате.
16. **/set-voice-hub** `channel:#канал`
    > Назначает существующий канал хабом для создания комнат.

### 🎫 Тикет-система
17. **/setup-tickets** `channel_for_panel:#канал` `category:Категория`
    > Отправляет интерактивную панель с кнопкой для создания обращений.
18. **/edit-ticket-panel** `channel:#канал` `message_id:ID`
    > Редактирование текста и кнопки отправленной панели.
19. **/edit-ticket-form**
    > Настройка полей окна создания тикета (тема, описание).
20. **/edit-ticket-welcome**
    > Настройка приветственного сообщения внутри тикета.
21. **/set-ticket-log-channel** `channel:#канал`
    > Канал для сохранения транскриптов закрытых обращений.

### 📜 Логи и аудит
22. **/set-log-channel** `channel:#канал-логов`
    > Устанавливает канал аудита сервера.
23. **/test-log**
    > Проверяет отправку тестового лога в канал.
24. **/bot-status**
    > Текущие настройки сервера, активные розыгрыши и пинг.
25. **/help**
    > Полная справка по боту.
26. `!sync`
    > Принудительная синхронизация слэш-команд администратором.

## 📁 Структура проекта
```
discord_bot/
├── bot.py             # Главная точка входа, запуск бота и синхронизация команд
├── config.py          # Модуль конфигурации и сохранения настроек в JSON
├── requirements.txt   # Необходимые библиотеки Python (discord.py, python-dotenv)
├── run.bat            # Скрипт быстрого запуска для Windows
├── .env               # Файл с вашим токеном
├── .env.example       # Шаблон конфигурационного файла
├── cogs/
│   ├── logging.py     # Логирование сообщений, участников, голосовых, ролей, каналов
│   ├── tickets.py     # Система тикетов (кнопки, модалки, транскрипты, закрытие)
│   ├── voice.py       # Динамические временные войсы ("Join to Create")
│   ├── admin.py       # Слэш-команды настройки (/setup-tickets, /set-log-channel, /set-autorole)
│   ├── levels.py      # Система уровней, опыта (чат + войс), карточек ранга и наград ролями
│   └── giveaways.py   # Интерактивные розыгрыши (кнопки, таймеры, победители, ЛС, условия)
└── data/
    ├── settings.json  # Настройки серверов
    ├── levels.json    # База данных опыта, уровней и статистики активности
    └── giveaways.json # База данных розыгрышей и участников
```
