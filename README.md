# 🤖 Discord Бот (Аудит Логи + Тикет-система)

Мощный и готовый к работе бот для Discord на Python (`discord.py` 2.x) со встроенным подробным логированием всех действий на сервере и полноценной интерактивной системой тикетов (кнопки, модальные окна, автоматические транскрипты переписки).

---

## 📋 Возможности бота

### 1. 📜 Полное логирование действий на сервере (Аудит)
Бот отправляет красивые Embed-уведомления в настроенный канал логов:
- **Сообщения**:
  - Удаление сообщений (автор, канал, текст, прикрепленные файлы).
  - Редактирование сообщений (текст «до» и «после», ссылка на сообщение).
- **Участники**:
  - Вход нового участника (с датой создания аккаунта и общим счётчиком участников).
  - Выход участника (с информацией о ролях и времени на сервере).
  - Изменение никнейма на сервере.
  - Изменение ролей участника (какие роли выданы / сняты).
  - Выдача и снятие таймаута (мута) модерацией.
- **Голосовые каналы**:
  - Подключение к каналу, отключение, перемещение между каналами.
- **Модерация**:
  - Блокировка (бан) с указанием модератора и причины из журнала аудита.
  - Разблокировка (разбан).
- **Каналы и роли**:
  - Создание, удаление и изменение каналов (тема, медленный режим, имя).
  - Создание, удаление и изменение ролей (название, цвет, права).

---

### 2. 🎫 Полноценная тикет-система
- **Интерактивная панель**: сообщение с кнопкой `📩 Создать тикет` в выбранном канале.
- **Модальное окно**: при нажатии пользователю открывается форма для ввода темы и описания проблемы.
- **Приватность**: создается закрытый текстовый канал, доступный только автору тикета и роли поддержки/администраторам.
- **Управление внутри тикета**:
  - 🔒 **Закрыть**: закрывает тикет с подтверждением, генерирует файл транскрипта (`.txt`), отправляет его в ЛС автору и в канал логов тикетов, после чего безопасно удаляет канал.
  - 📑 **Транскрипт**: выгрузка текущей переписки прямо во время диалога.
  - 🙋‍♂️ **Принять тикет**: модератор может закрепить обращение за собой.
- **Постоянство (Persistent Views)**: кнопки продолжают работать даже после перезагрузки бота!

---

### 3. 🔊 Динамические голосовые каналы (Join to Create)
- **Авто-создание**: при входе в хаб-канал (например, `➕ Создать канал`) бот моментально создаёт для пользователя личный голосовой канал и перемещает его туда.
- **Интерактивная панель в чате войса**: в текстовый чат голосового канала отправляется панель с кнопками:
  - ✏️ **Название** — сменить название своего голосового канала через всплывающее окно.
  - 👥 **Лимит** — установить ограничение количества участников (0–99).
  - 🔒 **Закрыть / Открыть** — переключение доступа в канал для остальных участников.
  - 👁️ **Скрыть / Показать** — скрыть канал из списка серверов для других.
  - 🚫 **Выгнать** — меню исключения и блокировки нежелательного участника в канале.
  - 👑 **Передать права** — передать право владения комнатой другому участнику.
  - 🗑️ **Удалить** — закрыть и удалить комнату вручную.
- **Авто-очистка**: как только все участники покидают комнату, бот автоматически удаляет пустой канал.
- **Передача владельца**: если создатель выходит, пока в канале есть другие люди, статус владельца передаётся следующему участнику.

## 🚀 Пошаговая инструкция по настройке и запуску

### Шаг 1. Создание бота на портале Discord
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **«New Application»** в правом верхнем углу, введите имя (например, `ServerAssistant`) и подтвердите.
3. В меню слева перейдите во вкладку **«Bot»**:
   - Нажмите **«Reset Token»**, скопируйте полученный токен (сохраните его, он понадобится в `.env`).
4. **ВАЖНО! Включение Intents (Намерения шлюза):**
   - На этой же странице во вкладке **«Bot»** прокрутите вниз до раздела **«Privileged Gateway Intents»**.
   - Включите все три галочки:
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent** *(нужен для логов входа/выхода/ролей участников)*
     - ✅ **Message Content Intent** *(нужен для чтения и логирования текста сообщений)*
   - Нажмите **«Save Changes»** внизу.

---

### Шаг 2. Приглашение бота на ваш сервер
1. В левом меню выберите **«OAuth2»** ➔ **«URL Generator»**.
2. В блоке **Scopes** отметьте:
   - ✅ `bot`
   - ✅ `applications.commands` (для слэш-команд `/`)
3. В появившемся блоке **Bot Permissions** выберите:
   - ✅ `Administrator` (рекомендуется для корректной работы всех функций тикетов и аудита)
   *(или выберите: Manage Channels, Manage Roles, View Audit Log, View Channels, Send Messages, Embed Links, Attach Files, Read Message History)*
4. Скопируйте ссылку в самом низу (**Generated URL**), откройте в браузере и добавьте бота на ваш сервер.

---

### Шаг 3. Настройка токена
1. В папке с ботом найдите файл `.env`.
2. Откройте его в блокноте или любом редакторе и вставьте ваш токен:
   ```env
   DISCORD_TOKEN=ваш_скопированный_токен_здесь
   COMMAND_PREFIX=!
   ```
3. Сохраните файл.

---

### Шаг 4. Запуск бота
- **Способ 1 (самый простой для Windows):**
  Дважды кликните по файлу **`run.bat`**.
  Он сам проверит зависимости и запустит бота.

- **Способ 2 (через терминал/командную строку):**
  ```bash
  python -m pip install -r requirements.txt
  python bot.py
  ```

## 🛠️ Настройка на сервере Discord (Слэш-команды)

После запуска бота введите на вашем сервере следующие слэш-команды:

1. **/set-log-channel** `channel:#канал-логов`
   > Устанавливает канал, в который бот будет присылать логи всех событий сервера.

2. **/setup-tickets**
   - `channel_for_panel`: текстовый канал, куда отправить сообщение с кнопкой «Создать тикет» (например, `#поддержка`).
   - `category`: категория каналов, внутри которой бот будет создавать тикеты (например, категория `ТИКЕТЫ`).
   - `support_role` *(опционально)*: роль модераторов/хелперов, которым будет открыт доступ к тикетам.
   - `ticket_log_channel` *(опционально)*: отдельный канал для отправки транскриптов закрытых обращений.
   - `panel_title` *(опционально)*: свой заголовок сообщения.
   - `panel_description` *(опционально)*: свой текст описания (можно использовать `\n` для переноса строк).
   - `button_text` *(опционально)*: своя надпись на кнопке (по умолчанию «Создать тикет»).
   - `panel_footer` *(опционально)*: своя нижняя подпись.

3. **/edit-ticket-panel** `channel:#канал` `message_id:ID_сообщения`
   > Открывает всплывающее окно прямо в Discord для редактирования текста уже отправленной панели (заголовок, описание, текст кнопки, подпись).

4. **/edit-ticket-form**
   > Открывает окно настройки полей, которые заполняет пользователь при создании тикета (заголовок окна, названия полей и подсказки-плейсхолдеры).

5. **/edit-ticket-welcome**
   > Открывает окно настройки приветственного сообщения и заголовка внутри только что созданного тикета.

6. **/setup-voice** `category:Категория` `hub_name:➕ Создать канал`
   > Создаёт в указанной категории голосовой хаб. При входе в него бот мгновенно создаёт участнику приватную комнату и отправляет в чат войса панель управления.

7. **/set-voice-hub** `channel:#канал`
   > Назначает уже существующий голосовой канал точкой авто-создания комнат.

8. **/bot-status**
   > Показывает текущую конфигурацию бота для сервера и пинг.

9. **/help**
   > Выводит подробную интерактивную справку по возможностям бота.

## 📁 Структура проекта
```
discord_bot/
├── bot.py             # Главная точка входа, запуск бота и синхронизация команд
├── config.py          # Модуль конфигурации и сохранения настроек в JSON
├── requirements.txt   # Необходимые библиотеки Python (discord.py, python-dotenv)
├── run.bat            # Скрипт быстрого запуска для Windows
├── .env               # Файл с вашим токеном
├── .env.example       # Шаблон конфигурационного файла
├── cogs/
│   ├── logging.py     # Логирование сообщений, участников, голосовых, ролей, каналов
│   ├── tickets.py     # Система тикетов (кнопки, модалки, транскрипты, закрытие)
│   └── admin.py       # Слэш-команды настройки (/setup-tickets, /set-log-channel и др.)
└── data/
    └── settings.json  # База данных настроек сервера и открытых тикетов
```
