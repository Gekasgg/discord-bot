# 🤖 Discord Бот (Аудит Логи + Тикет-система)

Мощный и готовый к работе бот для Discord на Python (`discord.py` 2.x) со встроенным подробным логированием всех действий на сервере и полноценной интерактивной системой тикетов (кнопки, модальные окна, автоматические транскрипты переписки).

---

## 📋 Возможности бота

### 1. 📜 Полное логирование действий на сервере (Аудит)
Бот отправляет красивые Embed-уведомления в настроенный канал логов:
- **Сообщения**:
  - Удаление сообщений (автор, канал, текст, прикрепленные файлы).
  - Редактирование сообщений (текст «до» и «после», ссылка на сообщение).
- **Участники**:
  - Вход нового участника (с датой создания аккаунта и общим счётчиком участников).
  - Выход участника (с информацией о ролях и времени на сервере).
  - Изменение никнейма на сервере.
  - Изменение ролей участника (какие роли выданы / сняты).
  - Выдача и снятие таймаута (мута) модерацией.
- **Голосовые каналы**:
  - Подключение к каналу, отключение, перемещение между каналами.
- **Модерация**:
  - Блокировка (бан) с указанием модератора и причины из журнала аудита.
  - Разблокировка (разбан).
- **Каналы и роли**:
  - Создание, удаление и изменение каналов (тема, медленный режим, имя).
  - Создание, удаление и изменение ролей (название, цвет, права).

### 2. 🎫 Полноценная тикет-система
- **Интерактивная панель**: сообщение с кнопкой `📩 Создать тикет` в выбранном канале.
- **Модальное окно**: при нажатии пользователю открывается форма для ввода темы и описания проблемы.
- **Приватность**: создается закрытый текстовый канал, доступный только автору тикета и роли поддержки/администраторам.
- **Управление внутри тикета**:
  - 🔒 **Закрыть**: закрывает тикет с подтверждением, генерирует файл транскрипта (`.txt`), отправляет его в ЛС автору и в канал логов тикетов, после чего безопасно удаляет канал.
  - 📑 **Транскрипт**: выгрузка текущей переписки прямо во время диалога.
  - 🙋‍♂️ **Принять тикет**: модератор может закрепить обращение за собой.
- **Постоянство (Persistent Views)**: кнопки продолжают работать даже после перезагрузки бота!

---

### 3. 🔊 Динамические голосовые каналы (Join to Create)
- **Авто-создание**: при входе в хаб-канал (например, `➕ Создать канал`) бот моментально создаёт для пользователя личный голосовой канал и перемещает его туда.
- **Интерактивная панель в чате войса**: в текстовый чат голосового канала отправляется панель с кнопками:
  - ✏️ **Название** — сменить название своего голосового канала через всплывающее окно.
  - 👥 **Лимит** — установить ограничение количества участников (0–99).
  - 🔒 **Закрыть / Открыть** — переключение доступа в канал для остальных участников.
  - 👁️ **Скрыть / Показать** — скрыть канал из списка серверов для других.
  - 🚫 **Выгнать** — меню исключения и блокировки нежелательного участника в канале.
  - 👑 **Передать права** — передать право владения комнатой другому участнику.
  - 🗑️ **Удалить** — закрыть и удалить комнату вручную.
- **Авто-очистка**: как только все участники покидают комнату, бот автоматически удаляет пустой канал.
- **Передача владельца**: если создатель выходит, пока в канале есть другие люди, статус владельца передаётся следующему участнику.

58: ### 4. 🎁 Система интерактивных розыгрышей (Giveaways)
59: - **Интерактивные кнопки**: сообщение с кнопкой `🎉 Участвовать (N)` и `👥 Участники` (быстрый вход и выход по клику).
60: - **Автоматический таймер**: умный парсер времени (`30s`, `15m`, `2h`, `1d`, `1д`, `2ч`), автоматическое определение победителей при окончании времени.
61: - **Условия для участия**:
62:   - Обязательная роль (`required_role`).
63:   - Минимальный уровень активности на сервере (`min_level`) — полная интеграция с системой уровней!
64: - **Управление розыгрышами**:
65:   - Досрочное завершение с выбором победителей (`/gend`).
66:   - Перевыбор случайных победителей (`/greroll`).
67:   - Просмотр списка активных розыгрышей на сервере (`/glist`).
68:   - Отмена розыгрыша (`/gcancel`).
69: - **Надёжность**: состояние сохраняется в `data/giveaways.json`, кнопки продолжают работать даже после перезагрузки бота.

73: ## 🚀 Пошаговая инструкция по настройке и запуску
74: 
75: ### Шаг 1. Создание бота на портале Discord
76: 1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
77: 2. Нажмите **«New Application»** в правом верхнем углу, введите имя (например, `ServerAssistant`) и подтвердите.
78: 3. В меню слева перейдите во вкладку **«Bot»**:
79:    - Нажмите **«Reset Token»**, скопируйте полученный токен (сохраните его, он понадобится в `.env`).
80: 4. **ВАЖНО! Включение Intents (Намерения шлюза):**
81:    - На этой же странице во вкладке **«Bot»** прокрутите вниз до раздела **«Privileged Gateway Intents»**.
82:    - Включите все три галочки:
83:      - ✅ **Presence Intent**
84:      - ✅ **Server Members Intent** *(нужен для логов входа/выхода/ролей участников)*
85:      - ✅ **Message Content Intent** *(нужен для чтения и логирования текста сообщений)*
86:    - Нажмите **«Save Changes»** внизу.
87:

89: 
90: ### Шаг 2. Приглашение бота на ваш сервер
91: 1. В левом меню выберите **«OAuth2»** ➔ **«URL Generator»**.
92: 2. В блоке **Scopes** отметьте:
93:    - ✅ `bot`
94:    - ✅ `applications.commands` (для слэш-команд `/`)
95: 3. В появившемся блоке **Bot Permissions** выберите:
96:    - ✅ `Administrator` (рекомендуется для корректной работы всех функций тикетов и аудита)
97:    *(или выберите: Manage Channels, Manage Roles, View Audit Log, View Channels, Send Messages, Embed Links, Attach Files, Read Message History)*
98: 4. Скопируйте ссылку в самом низу (**Generated URL**), откройте в браузере и добавьте бота на ваш сервер.

102: ### Шаг 3. Настройка токена
103: 1. В папке с ботом найдите файл `.env`.
104: 2. Откройте его в блокноте или любом редакторе и вставьте ваш токен:

109:    ```
110: 3. Сохраните файл.

127: ## 🛠️ Настройка на сервере Discord (Слэш-команды)
128: 
129: После запуска бота введите на вашем сервере следующие слэш-команды:
130: 
131: ### 🎁 Розыгрыши (Giveaways)
132: 1. **/gstart** `prize:Приз` `duration:Время` `[winners:1]` `[channel:#канал]` `[description:Правила]` `[required_role:@Роль]` `[min_level:Уровень]`
133:    > Запускает интерактивный розыгрыш с кнопками, таймером и условиями (например `/gstart prize:Discord Nitro duration:1h winners:2`).
134: 2. **/gend** `message_id:ID`
135:    > Досрочно завершает розыгрыш и определяет победителей.
136: 3. **/greroll** `message_id:ID` `[winners:1]`
137:    > Выбирает новых случайных победителей среди участников завершенного розыгрыша.
138: 4. **/gcancel** `message_id:ID`
139:    > Отменяет розыгрыш без выбора победителей.
140: 5. **/glist**
141:    > Показывает список всех активных розыгрышей на сервере со ссылками и таймерами.
142: 
143: ### ⭐ Система уровней и активности (Leveling)
144: 6. **/rank** `[user:@пользователь]`
145:    > Показывает карточку активности: уровень, опыт (XP), полосу прогресса, место в топе сервера, количество сообщений и время в войсе.
146: 7. **/leaderboard**
147:    > Выводит таблицу лидеров сервера (Топ-10) по опыту и уровням с медалями 🥇, 🥈, 🥉.
148: 8. **/set-level-channel** `[channel:#канал]`
149:    > Назначает канал для поздравлений с новыми уровнями (или отправка в текущий).
150: 9. **/set-level-role** `level:5` `role:@Активный`
151:    > Настраивает автоматическую выдачу роли при достижении уровня.
152: 10. **/level-roles**
153:     > Список всех настроенных наград ролями за уровни.
154: 11. **/remove-level-role** `level:5`
155:     > Удаляет роль-награду за уровень.
156: 12. **/add-xp** / **/remove-xp** / **/reset-levels**
157:     > Управление опытом участников (выдача, списание, сброс).
158: 
159: ### 🎭 Автовыдача ролей (Autorole)
160: 13. **/set-autorole** `role:@Роль` *(опционально)*
161:     > Настраивает роль, выдаваемую каждому новому участнику при входе. Для отключения вызовите без роли.
162: 
163: ### 🔊 Динамические голосовые каналы
164: 14. **/setup-voice** `category:Категория` `hub_name:➕ Создать канал`
165:     > Создаёт хаб «Join to Create» с панелью управления комнатой в чате.
166: 15. **/set-voice-hub** `channel:#канал`
167:     > Назначает существующий канал хабом для создания комнат.
168: 
169: ### 🎫 Тикет-система
170: 16. **/setup-tickets** `channel_for_panel:#канал` `category:Категория`
171:     > Отправляет интерактивную панель с кнопкой для создания обращений.
172: 17. **/edit-ticket-panel** `channel:#канал` `message_id:ID`
173:     > Редактирование текста и кнопки отправленной панели.
174: 18. **/edit-ticket-form**
175:     > Настройка полей окна создания тикета (тема, описание).
176: 19. **/edit-ticket-welcome**
177:     > Настройка приветственного сообщения внутри тикета.
178: 20. **/set-ticket-log-channel** `channel:#канал`
179:     > Канал для сохранения транскриптов закрытых обращений.
180: 
181: ### 📜 Логи и аудит
182: 21. **/set-log-channel** `channel:#канал-логов`
183:     > Устанавливает канал аудита сервера.
184: 22. **/test-log**
185:     > Проверяет отправку тестового лога в канал.
186: 23. **/bot-status**
187:     > Текущие настройки сервера, активные розыгрыши и пинг.
188: 24. **/help**
189:     > Полная справка по боту.
190: 25. `!sync`
191:     > Принудительная синхронизация слэш-команд администратором.
